# agent-glassbox

Multi-Agent Runtime (CLI or chatbot-based)
Real reasoning, memory, tool use, message passing.
Can be run headless or through a CLI/chat interface.
Emits structured telemetry on every decision and action.


Observability Platform (“Agent Glass Box”)
Stores and visualizes all that telemetry.
